# ZeroTraceBrowser v0.5.1

Release date: 2026-05-30

`v0.5.1` is a stability checkpoint after the `v0.5.0` stable baseline. This release focuses on making Timeline navigation and viewer return behavior more predictable with very large photo libraries.

## Highlights

- Stabilized Timeline window navigation for deep historical ranges, such as jumping from `2009-07` down to older groups like `2004-04`.
- Improved viewer startup from Timeline mode by avoiding full-library context scans.
- Restored viewer previous/next navigation by loading the active Timeline window instead of only the selected month.
- Improved return-to-index behavior so the selected image is restored sooner after leaving viewer.
- Reduced aggressive Timeline preloading that could cause repeated jumps or uncontrolled upward loading.

## Timeline And Viewer

- Timeline mode now loads older groups on demand while preserving a bounded, predictable window.
- Viewer now receives Timeline window metadata from index and hydrates context through `/api/images/timeline-group`.
- Viewer no longer needs to scan `/api/images` from the beginning of the library to reach deep historical images.
- Returning from viewer restores the Timeline selection earlier, instead of waiting for the full Timeline window rebuild to finish.
- Newer-month loading at the top boundary is intentionally conservative to avoid runaway preloading.

## Stability Notes

- This release is intended as a rollback checkpoint for the `v0.5.x` development line.
- The remaining Timeline boundary behavior is conservative by design: some upward loading requires user scroll interaction rather than automatic preloading.
- The tested focus was a large local photo library of roughly 70,000 images, with deep Timeline navigation and viewer round trips.
