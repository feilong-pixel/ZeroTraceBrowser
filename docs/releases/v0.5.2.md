# ZeroTraceBrowser v0.5.2

Release date: 2026-05-31

`v0.5.2` is a conservative hardening release after the `v0.5.1` Timeline stability checkpoint. It focuses on preserving the speed gains from the current system while tightening import, delete, repair, and duplicate-index boundaries.

## Highlights

- Clarified the producer/consumer boundary for import writes and repair flows.
- Hardened indexed metadata repair so gallery indexes and hash caches stay consistent across root-scoped runtime data.
- Strengthened delete and restore behavior around duplicate records, file hash cache state, and user-flow tests.
- Preserved Timeline month entries during single-image delete when other indexed images remain, avoiding a needless Timeline rebuild after cleanup.
- Expanded iPhone, mobile sync, duplicate, task, and user-flow regression coverage for the current local-first workflow.
- Kept generated homepage artifacts out of this application repository via `.gitignore`.

## Stability Notes

- This release is intended as the final `v0.5.x` checkpoint for the 2026-05-31 speed and boundary-hardening pass.
- No cloud upload behavior is introduced.
- No automatic organization, move, or delete behavior is introduced.
- User originals continue to follow the app-level recycle path for image delete flows.
- Runtime data remains root-scoped under `data/roots/<root_id>/`.
