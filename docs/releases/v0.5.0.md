# ZeroTraceBrowser v0.5.0

Release date: 2026-05-29

`v0.5.0` is the first stable usable baseline for ZeroTraceBrowser. This release focuses on making the core local photo workflow predictable and controllable with large libraries.

## Highlights

- Viewer first-paint is prioritized: the selected image is displayed before the full gallery context finishes loading.
- Viewer context now hydrates in the background, then restores previous/next navigation when ready.
- Timeline jumps now use lightweight database-backed group queries instead of full-index filtering.
- Timeline browsing can continue across adjacent months while scrolling.
- Returning from viewer to index restores the relevant Timeline position and selected image more reliably.
- Duplicate cleanup and recycle workflows have been tightened into a stable daily-use loop.
- iPhone import and local browsing now fit into the same controlled local-first workflow.

## Timeline And Viewer

- Added lightweight `/api/images/timeline-group` queries for fast month-level Timeline loading.
- Added `/api/images/timeline-neighbor` to find adjacent Timeline groups without loading the full Timeline index.
- Added adjacent-month preloading around Timeline jumps.
- Added continuous Timeline neighbor loading while scrolling near loaded boundaries.
- Preserved the current viewport anchor when newer Timeline groups are inserted above the current view.
- Improved viewer startup so image rendering is not blocked by list/context loading.

## Stability Notes

- The system is intentionally conservative: some operations may still feel slightly slower than an aggressively cached UI, but behavior should remain predictable and recoverable.
- This release is intended as a stable local-use baseline for large photo libraries.
- Future `v0.5.x` releases should focus on polishing and hardening this baseline rather than broad feature expansion.
